# data/navSat/ — navSat 场景仿真数据

近地与地月空间导航卫星时空基准项目的仿真数据。由
[app/navSat_simulation.f90](../../app/navSat_simulation.f90) 一次运行生成
（在仓库根目录执行 `./bin/navSat_simulation.exe`，同名文件被覆盖）。

场景：**3 颗 MEO 卫星 + 1 个地面站（北京）**，两两建立 access —— 3 条星间链路
+ 3 条星地链路，全部为测距（RANGING）。弧长 1 天（2025-01-01 00:00:00 UTC 起），
采样 30 s，共 2881 个历元。卫星状态量用位置速度（笛卡尔），钟差非零且三星各不相同；
地面站钟取零，作时间基准。观测不含测量噪声。

## 文件

| 文件 | 内容 |
|------|------|
| `eph_MEO1.txt` 等 3 个 | 卫星星历真值。`#` 文件头（含坐标系 J2000 与时间系统 UTC 的说明）之后，每行 `MJD日 MJD秒 X Y Z Vx Vy Vz`（km, km/s, J2000） |
| `clock_MEO1.txt` 等 3 个 | 卫星钟真值：解析模型参数 + 钟差表（2881 行，每行 `MJD日 MJD秒 钟差/s`） |
| `obs_<链路名>.txt` | 测距观测，6 个文件：`obs_MEO1-MEO2.txt`、`obs_MEO1-MEO3.txt`、`obs_MEO2-MEO3.txt`、`obs_MEO1-Beijing.txt`、`obs_MEO2-Beijing.txt`、`obs_MEO3-Beijing.txt`。每行 `MJD日 MJD秒 距离/km` |
| `odEph_MEO?.txt` | **定轨输出**：估计星历，格式同 `eph_MEO?.txt` |
| `odClk_MEO?.txt` | **定轨输出**：估计出的卫星钟模型，格式同 `clock_MEO?.txt`（`calc method` 恒为 FORMULA，无钟差表） |

观测文件与钟差文件都带自描述的 `#` 文件头，由 `type_access%readData` /
`type_clock%readData` 直接读回（读取时跳过 `#`/空行，坏行报警告并跳过）。

## 观测模型

```
rho_obs = rho_true + (clk_R - clk_T) * c
t_obs   = t_true + clk_R
```

即"接收端计时"：测距值含收发两端钟差之差，观测历元按**接收设备**的钟面时间标记。

- 星地链路：接收端是地面站，站钟恒为 0 → 历元不偏移，测距值只含卫星钟差项。
- 星间链路：接收端是接收星 → 历元偏移量即该星的钟差（约 1e-9 s 量级），
  测距值含两星钟差之差。

真值钟差由解析模型**直接计算**（`calcMethod = CLOCK_METHOD_FORMULA`，公式法）：

```
bias(t) = bias0 + drift*dt + drift2*dt^2 ,  dt = t - t0 [s]
```

三颗星的模型参数各不相同：MEO1 `bias0 = 1.2e-9 s, drift = 1.5e-14 s/s`，
MEO2 `-2.8e-9 s, 8.0e-15 s/s`，MEO3 `1.0e-9 s, 2.5e-14 s/s`（完整参数见各自的
`clock_MEO?.txt`）。**量级刻意压到钟差引起的测距偏差 `|bias|*c <= 1 m`**
（全弧最大 0.88 / 0.86 / 0.99 m）。这个量级是刻意选的：定轨程序若不估计钟差，
这 1 m 会作为系统性误差被吸收进轨道（实测位置误差 5~6 m，而钟差为零时只有 6 mm）；
`navSat_OD` 现在把这三颗星的钟差（`label 13` 钟差组）与轨道、ECOM 一起估计，
地面站钟固定为 0 作绝对时间基准，估计结果落在 `odClk_MEO?.txt`。

`clock_MEO?.txt` 里另附一张按场景历元（2881 点、30 s 间隔）生成的钟差表 —— 仿真
本身不查表（观测中的钟差一律由公式直接求值），这张表只是把钟差序列落盘，便于
查看与比对；文件头声明的计算方法仍是 `FORMULA (1)`，所以按文件读回后查任意时刻
（包括上面越界的星间观测历元）都用公式，不受表范围限制。若要改用表插值，需自行
把 `calcMethod` 置为 `CLOCK_METHOD_INTERPOLATION`，此时查询不得超出表范围。

## 已知的取值约定

- **可重现**：仿真全程不含随机量（钟差用解析公式，观测不加噪声），重复运行
  得到逐字节相同的文件。
- 距离单位 km，角度单位 deg，钟差单位 s；钟差符号为 `卫星钟面时间 − 参考时间`。
- 星间链路已按地球遮挡剔除视线穿过地球（含 80 km 大气层余量）的历元，
  1 天内约 14% 的历元被剔除；星地链路按仰角 ≥ 10° 筛选，且**不**剔除地影
  内的历元（测距是无线电链路）。
- 卫星力模型：非球形引力（degree = order = 12，即满 12x12）+ 月球三体 + 太阳三体 + 太阳光压（ECOM
  模型，9 参数框架里启用 5 个：D0、Y0、B0、Dc、Ds，其余为 0）；MEO 高度大气
  阻力可忽略，未开。后续定轨程序需用同一力模型，否则真值与模型不匹配。
